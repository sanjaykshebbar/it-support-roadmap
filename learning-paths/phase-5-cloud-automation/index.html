PHASE 5

Cloud Computing & Automation

Build the cloud infrastructure knowledge and scripting skills that every modern IT support professional needs.

4 Modules
Total ~8 hours
Intermediate
☁️

What You'll Master

This phase covers the essentials of cloud computing — from core concepts through hands-on Azure and AWS practice — plus automation scripting in both PowerShell and Bash. By the end, you'll be able to provision cloud resources, write scripts that automate routine IT tasks, and understand how cloud services fit into enterprise IT support workflows.

Linux ITIL Scripting

✅ Learning Outcomes

  • Explain cloud service models (IaaS, PaaS, SaaS) and deployment types with real-world examples
  • Navigate Azure and AWS consoles to create VMs, configure storage, and manage security groups
  • Write PowerShell scripts for Active Directory user management and system administration tasks
  • Create Bash scripts that automate routine Linux/Unix system checks and maintenance
  • Understand ITIL service management concepts including ticket lifecycles and SLA definitions
  • Compare major ticketing platforms (Jira Service Management, Freshservice, Zendesk) for enterprise use
  • Schedule automated tasks using cron jobs and Windows Task Scheduler
  • Apply cloud and automation knowledge to real IT support scenarios

🚀 What Comes Next

  1. Start with Cloud Computing Fundamentals to build your theory foundation
  2. Follow the hands-on labs in Azure & AWS Basics for practical cloud experience
  3. Complete PowerShell Scripting for Windows automation skills
  4. Finish with Bash Scripting & IT Service Management for Linux and ITSM knowledge
  5. Once all four modules are done, move to Phase 6: Career Preparation
