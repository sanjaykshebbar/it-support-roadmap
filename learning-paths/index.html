Phase 1 ~40 hours

Build Your Foundation

Computer hardware, basic networking concepts, command line fundamentals, and how operating systems work under the hood.

  • How computers work: CPU, RAM, storage, motherboard
  • Networking basics: IP addresses, DNS, routers
  • Command line comfort: CMD, PowerShell, Bash
  • OS navigation and file management
  • Hardware components and upgrades

Phase 2 ~60 hours

Operating Systems Deep Dive

Master Windows 10/11 administration, Linux fundamentals, macOS enterprise basics, and build a virtual home lab.

  • Windows 10/11 installation and configuration
  • Linux basics: Ubuntu/Debian file system, permissions
  • macOS fundamentals for enterprise support
  • VirtualBox home lab setup
  • Multi-OS troubleshooting practice
A+ 220-1101 Prep Open Guide →
Phase 3 ~80 hours

Networking Essentials

OSI model, TCP/IP, subnetting, VLANs, core protocols, router/switch basics, and hands-on network troubleshooting.

  • OSI and TCP/IP models deep dive
  • IP addressing, subnetting, VLANs, CIDR
  • Core protocols: DHCP, DNS, HTTP/S, SSH, RDP
  • Router and switch configuration basics
  • Troubleshooting: ping, traceroute, nslookup
  • Home network setup and configuration
Network+ Target Open Guide →
Phase 4 ~60 hours

Security Fundamentals

Common threats, encryption basics, firewalls, access control, endpoint security, user management, and incident response.

  • Threat landscape: malware, phishing, ransomware
  • Encryption, firewalls, and access control
  • User account management and password policies
  • Endpoint security: antivirus, EDR tools
  • Incident response fundamentals
Security+ Target Open Guide →
Phase 5 ~60 hours

Cloud & Automation

Cloud computing models, Azure/AWS basics, PowerShell and Bash scripting, ticketing systems, and remote desktop tools.

  • IaaS, PaaS, SaaS cloud models
  • Azure or AWS fundamentals hands-on
  • PowerShell scripting for automation
  • Bash scripting on Linux
  • Ticketing systems: Jira, Freshservice
  • Remote desktop tools and best practices

Career Preparation

Build your portfolio, nail your resume and interviews, develop a job search strategy, and prepare for your first IT role.

  • Portfolio building and documentation
  • Resume writing and interview prep
  • Job search strategy and networking
  • LinkedIn optimization for IT roles
  • Salary negotiation and career growth
