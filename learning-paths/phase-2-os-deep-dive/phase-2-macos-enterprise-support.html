Master macOS administration from installation through enterprise deployment, encryption, and troubleshooting.

    • Install and recover macOS systems confidently

    ~3 hours

    Lesson 1.1: Installing macOS

    Creating bootable installers, clean installs, and migration strategies.

    Lesson 6.2: Quarantine & Security

    xattr quarantine attribute, Gatekeeper, and bypassing for trusted software.

    Lesson 7.2: macOS-Specific Diagnostics

    Console.app log analysis, ASL (Apple System Logger), unified logging system.

    Quick Reference: Common Fixes

    SymptomCommand / Fix
    App won't launch (damaged)xattr -rd com.apple.quarantine /Applications/App.app
    DNS not resolvingsudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
    WiFi won't connectnetworksetup -setairportpower en0 off && on
    Finder frozenkillall Finder
    Login window freezesudo pkill -KILL -u 0 (use caution!)
    Slow startup appsSystem Settings > General > Login Items
    Corrupt launchpadrm ~/Library/Application\ Support/Dock/*.db && killall Dock
