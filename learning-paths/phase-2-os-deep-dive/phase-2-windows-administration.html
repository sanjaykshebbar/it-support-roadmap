Windows 10/11 Administration

Master enterprise Windows management from installation through troubleshooting and remote administration.

    Learning Objectives

    • Install and deploy Windows 10/11 using modern tools
    • Manage local users and Active Directory accounts
    • Author and enforce Group Policy Objects (GPOs)
    • Configure system settings and optimize performance
    • Navigate and edit the Windows Registry safely
    • Manage drivers and update systems
    • Implement backup and restore strategies
    • Use Event Viewer, DISM, SFC for diagnostics
    • Administer remotely via PowerShell and RMM tools

    Module 1: Windows Installation & Deployment

    ~3 hours

    Lesson 1.1: Media Creation & ISO Management

    Creating bootable media, managing WIM files, and preparing deployment packages for mass rollout.

    • Media Creation Tool workflow
    • ISO mounting and modification
    • Custom answer files (autounattend.xml)

    Lesson 1.2: Imaging with MDT/Litetouch

    Deploying standardized images across fleets using Microsoft Deployment Toolkit.

    • Deployment share setup and configuration
    • Task sequences for different roles
    • Driver injection and application packaging

    Hands-On Lab: Build Your First Task Sequence

    1. Install MDT on a Windows Server VM
    2. Create a Deployment Share with default structure
    3. Import the latest Windows 11 ISO as source
    4. Create a task sequence targeting Workstation role
    5. Bootstrap a test client and verify imaging works

    Real-World Scenario

    Your company is upgrading 500 PCs from Windows 10 to 11. The legacy image doesn't include the new TPM 2.0 driver signature. Design an automated upgrade path that handles driver gaps without user interaction.

    Module 2: User Management (Local & AD)

    ~3 hours

    Lesson 2.1: Local Account Management

    User profiles, groups, permissions, and account policies at the workstation level.

    • Computer Management console deep-dive
    • net user / net localgroup commands
    • Profile paths and roaming profiles basics

    Lesson 2.2: Active Directory Users & Computers

    AD domain concepts, OUs, organizational hierarchy, and bulk operations with PowerShell.

    • AD schema, domains, forests, trusts
    • SUBNETS and site topology
    • PowerShell Get-/New-/Set-ADUser workflows
    • Password policies and lockout thresholds

    Hands-On Lab: AD User Lifecycle

    1. Set up a Windows Server 2022 VM and promote it to domain controller
    2. Create organizational units for each department
    3. Use PowerShell to create 50 sample users in bulk
    4. Lock and unlock accounts using multiple methods
    5. Audit failed login attempts across the domain

    Real-World Scenario

    An employee leaves today. You need to disable their account, redirect their Outlook cache, move their file share to an administrator, and revoke all session tokens within 5 minutes. Document your runbook.

    Module 3: Group Policy Administration

    ~4 hours

    Lesson 3.1: GPO Anatomy & Processing Order

    Understanding policy precedence, inheritance blocking, and the order of operations.

    • LSDOU: Local, Site, Domain, OU processing
    • Block Inheritance and Enforced options
    • gpresult and RSOP analysis tools

    Lesson 3.2: Authoring & Enforcing Policies

    Crafting real-world GPOs for security hardening, software restrictions, and drive mapping.

    • Security templates and baseline hardening
    • AppLocker for application control
    • Drive mappings, printers, and logon scripts
    • Preference items vs. classic settings

    Hands-On Lab: Security Baseline Rollout

    1. Create a GPO enforcing password complexity matching NIST guidelines
    2. Configure screen timeout and blanking policies
    3. Deploy mapped drives based on AD group membership
    4. Use gpupdate /force and troubleshoot a misconfigured policy

    Real-World Scenario

    The CISO wants all USB storage blocked except encrypted devices for the finance team. How do you scope this policy using security filtering and WMI filters?

    Module 4: System Configuration & Performance

    ~2.5 hours

    Lesson 4.1: Services & Startup Management

    Controlling Windows services, startup programs, and understanding service dependencies.

    • Services.msc and sc.exe command-line control
    • Startup folder and registry run keys
    • msconfig and Task Manager alternatives

    Lesson 4.2: System Monitoring & Optimization

    Performance Monitor, Resource Monitor, and common bottlenecks in enterprise environments.

    • PerfMon counters: CPU, Memory, Disk, Network
    • Reliability Monitor for stability tracking
    • Memory leak detection and disk fragmentation analysis

    Hands-On Lab: Root Cause Analysis

    1. Introduce a memory-hogging process (simulate with loop script)
    2. Use PerfMon to identify and document the bottleneck
    3. Troubleshoot a deliberately misconfigured DNS client
    4. Check event logs for the specific error pattern

    Module 5: Registry Editing

    ~2 hours

    Lesson 5.1: Registry Structure & Hives

    Navigating HKLM, HKCU, hive structure, and safe modification techniques.

    • Key relationships and data types
    • Registry export/import best practices
    • Built-in backdoors and undocumented features

    Lesson 5.2: Common Enterprise Registry Tweaks

    Policies deployed via registry vs. GPO, known-good values for common issues.

    • Disabling telemetry and data collection keys
    • Fixing common Explorer/Shell problems
    • Remote assistance and RDP tunneling registry entries

    Hands-On Lab: Safe Registry Surgery

    1. Export a critical registry key before modification
    2. Disable Adobe Flash notifications via registry
    3. Change the default printer via HKCU registry entry
    4. Restore from backup using reg import command

    Real-World Scenario

    A user cannot connect to a network drive because the registry has been corrupted. Rebuild the relevant MRU list and network connection settings from scratch using HKCU\Network keys.

    Module 6: Driver Management & Updates

    ~2 hours

    Lesson 6.1: Device Manager Deep Dive

    Installing, updating, rolling back, and troubleshooting hardware drivers.

    • Driver stores and INF files (pnputil)

    2. Use pnputil to enumerate and add a driver package
    3. Configure WSUS in a lab domain controller scenario

    Module 7: Backup & Restore Strategies

    ~2.5 hours

    Lesson 7.1: Built-in Tools: File History & System Image

    Using Windows native backup features for personal and enterprise scenarios.

    • File History retention policies and library selection
    • Backup and Restore (Windows 7) for system images
    • Windows Server Backup for server workloads

    Lesson 7.2: Shadow Copies & VSS

    Volume Shadow Copy Service for instant file recovery without third-party tools.

    • Shadow Copy scheduling and storage allocation
    • Previous Versions tab recovery
    • VSS writer status checks and fixing stuck shadows

    Hands-On Lab: Disaster Recovery Simulation

    1. Configure File History on a test machine pointing to a network share
    2. Enable shadow copies on C: with 10% allocation
    3. Delete a critical file and recover it using Previous Versions
    4. Perform a full system image backup and restoration in recovery mode

    Real-World Scenario

    A ransomware attack hits. Some machines have shadow copies disabled. Draft an incident response plan covering immediate containment, identification of immutable backups, and rebuilding from clean media within 2 hours.

    Module 8: Troubleshooting Tools

    ~3 hours

    Lesson 8.1: Event Viewer Mastery

    Reading Security, System, and Application logs, custom views, and log aggregation.

    • Event ID patterns: logon failures (4625), access denied (4663)
    • Forwarded Events subscription architecture
    • Filtering and creating custom views for rapid triage

    Lesson 8.2: SFC & DISM Repair

    Fixing corrupt system files and component store corruption systematically.

    • sfc /scannow and its limitations
    • DISM cleanup-image repair from Windows source
    • Online vs. offline component store repair

    Hands-On Lab: Diagnostic Workflow

    1. Search Event Viewer for all Critical and Error events in last 24 hours
    2. Run sfc /scannow on a healthy system and interpret results
    3. Run DISM /Cleanup-Image /RestoreHealth from a mounted ISO
    4. Create a custom view showing only Security audit failures

    Real-World Scenario

    A workstation boots to a black screen. The monitor shows no output after the BIOS. Using only keyboard navigation, diagnose whether it's a display driver issue or deeper system corruption using WinRE and CMD-only tooling.

    Windows Event Log Reference DISM Best Practices

    Module 9: Remote Management

    ~3 hours

    Lesson 9.1: Remote Desktop Protocol (RDP)

    RDP configuration, gateway setups, session management, and security hardening.

    • rdp / remote desktop connections advanced settings
    • RD Gateway for internet-accessible management
    • Multi-session RDS deployments overview

    Lesson 9.2: PowerShell Remoting (WinRM)

    Secure remote execution, PSSession configurations, and automation patterns.

    • WinRM service prerequisites and firewall rules
    • New-PSSession, Enter-PSSession, Invoke-Command
    • TrustedHosts and certificate-based authentication

    Hands-On Lab: Remote Fleet Management

    1. Enable WinRM on a target machine via GPO
    2. Execute multi-machine commands using Invoke-Command -ComputerName
    3. Configure RDS (Remote Desktop Services) connection broker
    4. Build a PowerShell script that pings all computers in an OU and reports uptime

    Real-World Scenario

    You need to push a script to 200 machines but half are behind a firewall with no WinRM access. Design a fallback strategy using PSExec, SSH bastion, or RMM agent deployment to achieve the same result.
