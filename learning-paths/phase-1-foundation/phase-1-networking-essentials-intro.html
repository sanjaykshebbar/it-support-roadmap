Networking Essentials

Understand how computers communicate. From IP addresses and cables to the magic of DNS and DHCP, this module covers the foundational plumbing of the internet.

🕐 ~2.5 Hours 🌐 Network Fundamentals CompTIA A+ 220-1101 Essential Skill

Learning Objectives

  • Define LAN, WAN, and WLAN and their typical use cases
  • Understand IPv4 addressing, subnet masks, and default gateways
  • Differentiate between Private and Public IP addresses
  • Explain the roles of Routers and Switches in a network
  • Identify common network cables (Cat5e, Cat6, Fiber) and connectors (RJ45)
  • Describe how DNS resolves names to IP addresses
  • Explain how DHCP automates IP address assignment
  • Identify common network topologies like Star and Mesh

Module 1: What is a Network?

~25 min

Defining the Network

A network is simply two or more computers connected together to share resources (files, printers, internet).

  • LAN (Local Area Network): A small geographic area like a home, office, or building.
  • WAN (Wide Area Network): Covers a large geographic area (e.g., the Internet).
  • WLAN (Wireless LAN): A LAN that uses Wi-Fi instead of cables.
  • PAN (Personal Area Network): Very small range, like Bluetooth connecting your phone to your headphones.

Why networks matter in IT Support

Most "computer problems" are actually network problems. "I can't print," "The internet is slow," or "I can't reach the shared drive" all require network troubleshooting skills.

Module 2: IP Addressing Basics

~35 min

What is an IP Address?

An Internet Protocol (IP) address is a unique identifier for every device on a network. Think of it like a mailing address for your computer.

IPv4 Structure: Four numbers (octets) separated by dots, ranging from 0 to 255. (e.g., 192.168.1.15)

  • Subnet Mask: Defines which part of the IP is the "Network" and which is the "Host" (e.g., 255.255.255.0).
  • Default Gateway: The address of your router - your "exit" to the outside world.

Public vs Private IPs

  • Private IPs: Used inside your LAN. Usually start with 192.168.x.x, 10.x.x.x, or 172.16.x.x. They are not reachable from the internet.
  • Public IPs: Assigned to your router by your ISP. This is how the whole world sees your network.
  • Loopback Address: 127.0.0.1 - refers to "this computer" (localhost).

Hands-On Lab: Finding Your Identity

  1. Open CMD or PowerShell.
  2. Type ipconfig and press Enter.
  3. Identify your **IPv4 Address**, **Subnet Mask**, and **Default Gateway**.
  4. Type ping 127.0.0.1. If it responds, your network stack is working!

Module 3: Routers vs Switches

~30 min

The Switch: The Local Organizer

A switch connects multiple devices together **within the same network**. It uses MAC Addresses (hardware addresses) to send data to the correct port.

  • Unmanaged Switch: Plug and play.
  • Managed Switch: Allows configuration (VLANs, security).

The Router: The Gateway

A router connects **different networks** together (e.g., your home LAN to the Internet). It uses IP Addresses to route traffic between networks.

Analogy

Think of a Switch as the hallway in an apartment building (connecting rooms) and the Router as the front door (connecting the building to the street).

Module 4: Cables & Connectors

~25 min

Twisted Pair (Ethernet)

The standard cable for wired networks. Uses RJ45 connectors.

  • Cat5e: Supports up to 1 Gbps (100MHz).
  • Cat6: Supports up to 10 Gbps (shorter distances, 250MHz).
  • Cat6a: Supports 10 Gbps at full 100-meter distance (500MHz).
  • STP vs UTP: Shielded (STP) vs Unshielded (UTP). Use STP in high-interference environments.

Fiber Optic

Uses light instead of electricity. Immune to electromagnetic interference and supports much longer distances.

  • Single-mode: Long distance (miles).
  • Multi-mode: Shorter distance (inside buildings).

Wi-Fi Standards

  • 802.11ac (Wi-Fi 5): 5GHz band, very common.
  • 802.11ax (Wi-Fi 6): Faster, better for crowded areas.

Module 5: DNS & DHCP Explained

~30 min

DNS (Domain Name System)

The "Phonebook of the Internet." It translates human-friendly names (google.com) into computer-friendly IP addresses (142.250.x.x).

DHCP (Dynamic Host Configuration Protocol)

Automatically assigns IP addresses, subnet masks, and gateways to devices when they join a network. Without it, you'd have to manually type in an IP for every phone and laptop in your house!

Hands-On Lab: DNS Lookup

  1. Open your terminal.
  2. Type nslookup google.com.
  3. Observe the IP address returned. Try typing that IP address directly into your browser's address bar.

Module 6: Basic Topology

~20 min

Network Shapes

  • Star: All devices connect to a central switch. Most common in modern offices. If the switch fails, the whole network goes down, but if one cable fails, only one computer is affected.
  • Mesh: Every device connects to every other device. Extremely reliable (used in Wi-Fi mesh systems).
  • Bus: All devices share a single cable. Legacy, rarely seen now.

Protocol Quick Reference

HTTPS 443 Encrypted web traffic

Knowledge Check

Q1: What is the main difference between a Router and a Switch?

A switch connects devices on the same local network (using MAC addresses). A router connects different networks together (using IP addresses).

Q2: Which protocol is responsible for giving your computer an IP address automatically?

DHCP (Dynamic Host Configuration Protocol).

Q3: If you can ping 8.8.8.8 but cannot open 'google.com', what service is likely broken?

DNS (Domain Name System). You have connectivity to the internet, but your computer can't translate names to IPs.

Q4: What is the maximum distance for a standard Ethernet cable run?

100 meters (328 feet).
