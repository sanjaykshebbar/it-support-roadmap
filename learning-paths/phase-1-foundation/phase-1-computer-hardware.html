Computer Hardware Fundamentals

Understand every major component inside a computer, how they work together, and gain the hands-on skills to build, upgrade, and troubleshoot hardware confidently.

🕐 ~10 Hours 🔧 Hands-On Labs CompTIA A+ 220-1101 Beginner Friendly

Learning Objectives

  • Identify CPU architectures, sockets, and performance characteristics
  • Compare RAM types, speeds, and configurations (single vs dual channel)
  • Differentiate storage technologies: HDD, SATA SSD, NVMe, M.2
  • Understand motherboard form factors, chipsets, and expansion slots
  • Assemble and disassemble a desktop PC safely
  • Diagnose common hardware failures using systematic troubleshooting
  • Configure peripherals: printers, monitors, USB devices, docking stations
  • Evaluate laptop vs desktop tradeoffs for enterprise deployment
  • Plan and execute component upgrades (RAM, storage, PSU, cooling)
  • Apply ESD safety precautions in all hardware handling scenarios

Module 1: The Brain — CPU Fundamentals

~1.5 hours

Lesson 1.1: How CPUs Work

CPU (Central Processing Unit) is the brain of the computer. It executes instructions, performs calculations, and orchestrates all other components via the motherboard bus system.

  • Cores and threads: physical cores vs hyper-threading/SMT
  • Clock speed (GHz), boost clocks, and TDP (Thermal Design Power)
  • Cache hierarchy: L1, L2, L3 cache and why it matters
  • x86-64 vs ARM architectures in consumer and enterprise PCs

Lesson 1.2: CPU Sockets & Compatibility

Not all CPUs fit all motherboards. Socket type determines compatibility, and chipset features determine what else you can connect.

  • Intel sockets: LGA 1700 (12th-14th gen), LGA 1200 (10th-11th gen)
  • AMD sockets: AM4 (Ryzen 1000-5000), AM5 (Ryzen 7000+, DDR5 only)
  • Understanding BIOS/UEFI firmware updates for CPU support
  • Cooler compatibility: Intel vs AMD mounting standards

Real-World Scenario

A user complains their workstation runs slow during video calls but fine otherwise. You suspect a thermal throttling issue. Walk through diagnosing whether the CPU throttle-down is due to dust, failed thermal paste, or an incompatible cooler mount.

Module 2: Memory — RAM Deep Dive

~1.5 hours

Lesson 2.1: RAM Types & Generations

RAM (Random Access Memory) is the computer's short-term workspace. Understanding DRAM generations helps you select the right memory for any build.

  • DDR3 vs DDR4 vs DDR5: pin layouts, voltages, speeds
  • SO-DIMM (laptop) vs DIMM (desktop) physical differences
  • ECC vs non-ECC memory: when error correction matters
  • Registered (RDIMM) vs unbuffered (UDIMM) memory

Lesson 2.2: Memory Configurations & Performance

How you install RAM dramatically affects performance. Channel architecture and speed matching are critical considerations.

  • Single-channel vs dual-channel vs triple-channel vs quad-channel
  • XMP/EXPO profiles: enabling advertised speeds in BIOS
  • Mixing RAM kits: what happens when capacities/speeds differ
  • Memory timing latencies: CL, tRCD, tRP, tRAS explained

Hands-On Lab: RAM Upgrade & Diagnostics

  1. Open a desktop PC and identify existing RAM slots and type (DDR4/DDR5)
  2. Use cpuinfo / dxdiag / free command to document current memory config
  3. Install an additional compatible RAM stick in the correct slot for dual-channel
  4. Enter BIOS and enable XMP profile if available
  5. Run Windows Memory Diagnostic or MemTest86 to verify stability

Module 3: Storage Technologies

~2 hours

Lesson 3.1: HDD vs SSD — Core Differences

Storage is where your data lives permanently. Choosing between spinning disks and flash storage impacts speed, cost, capacity, and reliability.

  • HDD: platters, read/write heads, RPM speeds (5400 vs 7200), noise, power
  • SATA SSD: NAND flash, controller, 6 Gbps bottleneck, 500+ MB/s reads
  • NVMe SSD: PCIe lanes, M.2 form factor, 3000-12000+ MB/s throughput
  • QLC vs TLC vs MLC NAND: endurance (TBW) and lifespan tradeoffs

Lesson 3.2: Interfaces & Form Factors

Connecting storage requires matching both physical shape and data protocol.

  • 2.5-inch SATA (SSD/HDD): most common SATA form factor
  • 3.5-inch SATA: desktop HDD standard, higher capacities
  • M.2 2280 vs 2242 vs 2230: width x length dimensions
  • M.2 keys: B-key, M-key, B+M key and what they support
  • USB external drives: USB 3.0/3.1/3.2/4, Thunderbolt 3/4
  • SAS vs SATA in enterprise environments

Lesson 3.3: Storage Setup & Cloning

Installing new drives, migrating data, and configuring RAID arrays for redundancy or performance.

  • BIOS/UEFI drive boot order configuration
  • Disk management: partitioning, formatting NTFS/exFAT/ext4
  • Cloning tools: Macrium Reflect, Clonezilla, dd for Linux
  • Built-in RAID 0/1/10: performance vs redundancy tradeoffs

Hands-On Lab: Drive Installation & Migration

  1. Install a 2.5-inch SATA SSD into a desktop as a secondary drive
  2. Initialize, format, and assign a drive letter in Disk Management
  3. Clone an existing HDD to the new SSD using free cloning software
  4. Swap primary drives and update BIOS boot order to test the clone
  5. Verify system boots cleanly from the SSD and confirm performance gain

Real-World Scenario

An executive's laptop has only 128 GB of eMMC storage and is unusably slow. They need at least 512 GB for their workload. Options include replacing the internal drive, upgrading to an NVMe slot, or using a high-speed external solution. Assess each option's feasibility for a warranty-sensitive thin laptop.

Module 4: Motherboard & System Architecture

~1.5 hours

Lesson 4.1: Motherboard Form Factors

The motherboard is the backbone that connects everything. Form factor determines case compatibility, expansion slots, and overall capability.

  • ATX, Micro-ATX (mATX), Mini-ITX: size comparisons and use cases
  • Enterprise boards: E-ATX, workstation boards with more PCIe lanes
  • Laptop motherboards: highly integrated, rarely upgradeable
  • I/O shield presence and port layout variations

Lesson 4.2: Chipsets, Buses & Expansion Slots

Chipsets control what the CPU can communicate with. Understanding them helps you pick the right board for the job.

  • Intel chipsets: H, B, Z series — feature differences explained
  • AMD chipsets: A, B, X series — similarly tiered feature sets
  • PCIe generation differences: 3.0 vs 4.0 vs 5.0 bandwidth
  • SATA ports, M.2 sharing rules, and lane bifurcation quirks
  • VRM phases: why they matter for overclocking and stability

BIOS / UEFI

Firmware that initializes hardware at boot. Modern UEFI offers mouse support, network boot, and secure boot verification.

CMOS Battery

Keeps BIOS settings and real-time clock running when powered off. Dead battery = lost settings and wrong system time.

Power Connectors

24-pin ATX main, 8-pin EPS CPU, 6/8-pin PCIe GPU. PSU wattage must cover total system draw plus headroom.

Front Panel Headers

PWR_SW, RESET_SW, HDD_LED, PWR_LED, USB 2.0/3.0, audio HD_AUDIO. Pinouts vary by manufacturer.

Module 5: Power Supplies & Cooling

~1 hour

Lesson 5.1: PSU Wattage & Efficiency

The power supply delivers electricity to every component. Choosing the right PSU prevents instability, crashes, and hardware damage.

  • Wattage calculation: sum all component TDPs + 20% headroom
  • 80 PLUS certification: White, Bronze, Silver, Gold, Platinum, Titanium
  • Modular vs semi-modular vs non-modular cables
  • Rail configurations: single-rail vs multi-rail PSUs
  • ATX 3.0 / 12VHPWR connector for modern NVIDIA GPUs

Lesson 5.2: Cooling Solutions

Heat kills electronics. Proper cooling extends component life and maintains performance under load.

  • Air cooling: tower coolers, low-profile, stock heatsinks
  • All-in-one liquid coolers (AIO): 120mm, 240mm, 360mm radiators
  • Case airflow: intake fans, exhaust fans, positive pressure
  • Thermal paste application: pea method vs spread method
  • Monitoring temps with HWMonitor, Core Temp, or OpenHardwareMonitor

Hands-On Lab: Build Assessment & Thermal Check

  1. Identify the PSU wattage label on an open desktop chassis
  2. Calculate estimated system power draw from listed components
  3. Inspect fan placement and cable routing for optimal airflow
  4. Boot system and record idle/idle temperatures using monitoring tool
  5. Run a stress test (Prime95 or OCCT) and observe thermal behavior

Lesson 6.1: Display Outputs & Resolutions

  • G-Sync vs FreeSync: adaptive sync technologies

Lesson 6.2: Printers & Common Peripherals

Printers, webcams, docks, and other peripherals are daily touchpoints for IT support staff.

  • Inkjet vs laser vs LED printer technologies and use cases
  • Network printer setup: IP assignment, shared folders, print queues
  • USB device enumeration and driver installation
  • USB-C docking stations: display output passthrough, charging
  • KVM switches for multi-computer workflows

Real-World Scenario

A user reports their second monitor goes black randomly. Sometimes it works after wiggling the cable. Diagnose whether this is a faulty cable, bad HDMI port on the GPU, driver issue, or insufficient power delivery through the port. Test with known-good cables first.

Module 7: Laptop vs Desktop & Portability

~1 hour

Lesson 7.1: Enterprise Laptop Considerations

Businesses deploy laptops for mobility but face unique challenges around repairability, upgrades, and lifecycle management.

  • ThinkPad, Latitude, EliteBook — enterprise durability standards (MIL-STD)
  • User-replaceable components: RAM slots, SSD bays in business laptops
  • Battery health monitoring and replacement intervals
  • Lock slots, Kensington interfaces, and physical security
  • Webcam shutters, microphone mutes, privacy toggles on modern laptops

Lesson 7.2: Thin-and-Light vs Gaming vs Workstation

Understanding the trade-offs between ultraportables, performance laptops, and mobile workstations.

  • Thin-and-light: integrated GPU, limited cooling, best battery life
  • Gaming laptops: discrete GPUs, aggressive cooling, poor battery
  • Mobile workstations: ISV-certified GPUs, ECC RAM, xeon/mobile CPUs
  • Tablets/2-in-1s: detachable keyboards, stylus support, limited I/O
  • Docking station ecosystems: Dell WD-series, HP dock, Lenovo ThinkPad docks

Hands-On Lab: Laptop Hardware Tour

  1. Open a service manual for a specific laptop model (e.g., Dell Latitude 5520)
  2. Identify accessible upgrade locations: RAM slot, M.2 slot, Wi-Fi card
  3. Remove and reseat the existing RAM module
  4. Check battery cycle count and health status
  5. Replace the back panel and verify all ports and keys function

Module 8: Hardware Troubleshooting Methodology

~1.5 hours

Lesson 8.1: The IT Troubleshooting Process

A structured methodology prevents wasted time and missed root causes. Follow these steps for every hardware ticket.

  • Step 1: Identify the problem — gather symptoms from user and logs
  • Step 2: Establish a theory of probable cause — what could be failing?
  • Step 3: Test the theory — isolate variables one at a time
  • Step 4: Establish a plan of action — what fix will you apply?
  • Step 5: Verify full system functionality — does the fix work end-to-end?
  • Step 6: Document findings — knowledge base article for next time

Lesson 8.2: Diagnostic Tools & Beep Codes

Sometimes the answer comes before the OS even loads. POST codes and beep sequences tell you exactly which component is misbehaving.

  • POST (Power-On Self-Test): what happens before the OS starts
  • Beep code patterns for AMI, Award, and Phoenix BIOS
  • Diagnostic LEDs on modern motherboards (CPU / DRAM / VGA / BOOT)
  • Hardware diagnostic utilities: Built-in Dell diagnostics, HP PC Hardware Diagnostics
  • Minimimal boot testing: remove everything, add back one component at a time

Hands-On Lab: POST Diagnosis Challenge

  1. Power on a PC that won't post — listen for beep patterns or check debug LEDs
  2. Reseat all RAM modules and try booting again
  3. If still no display, swap the RAM stick into a known-good slot
  4. Disconnect non-essential peripherals and attempt minimal boot
  5. Test the system with a different power supply if available

Checkpoint: Can You Diagnose This?

A desktop makes no sound on power-up, no display, and no fans spin beyond a brief pulse. Which component is the most likely culprit? (Answer: PSU or front-panel power switch, not RAM — always check power first.)

Module 9: Safe Assembly & ESD Protection

~1 hour

Lesson 9.1: ESD Safety Procedures

Electrostatic discharge can silently destroy components worth hundreds of dollars. Always follow proper ESD precautions.

  • ESD wrist strap: clip to grounded metal, not paint or plastic
  • Anti-static mats and grounding points on workbenches
  • When you must touch a component: hold by edges, avoid pins and traces
  • Component storage: anti-static bags, original packaging when possible
  • Humidity matters: dry winter air increases ESD risk significantly

Lesson 9.2: Step-by-Step Desktop Build

Building from parts teaches you how everything fits together better than any textbook.

  • Prepare workspace: clean, well-lit, non-conductive surface
  • Install CPU onto motherboard before placing in case
  • Apply thermal paste correctly — tiny dot, never smear excessively
  • Install RAM into correct channels (check motherboard manual)
  • Mount motherboard standoffs matching your form factor
  • Connect front panel connectors carefully — refer to manual diagrams
  • First boot test: keep everything outside the case to rule out shorts

Hands-On Lab: Full Desktop Build

  1. Gather: motherboard, CPU, 1x RAM stick, PSU, case, M.2 SSD
  2. Install CPU into socket (align triangle marker, no force needed)
  3. Apply thermal paste and mount the CPU cooler
  4. Install RAM in the recommended dual-channel slot pattern
  5. Mount M.2 NVMe drive and secure with screw
  6. Place motherboard in case with standoffs, secure screws
  7. Connect 24-pin ATX and 8-pin EPS, then power on to verify POST

Draft a build checklist and quality-control procedure to ensure every unit passes POST and benchmark tests before shipping to users.

Knowledge Check — Quiz Yourself

Q1: What is the maximum theoretical bandwidth of PCIe 4.0 x16 compared to PCIe 3.0 x16?

Answer: PCIe 4.0 doubles the per-lane bandwidth (~32 GT/s vs ~16 GT/s), giving x16 roughly 64 GB/s vs 32 GB/s for PCIe 3.0.

Q2: Why should you NEVER open a CRT monitor casing?

Answer: CRTs store lethal voltage (~30,000V) in their capacitors even when unplugged. Only LCD/LED screens are safe to open without special training.

Q3: A user's PC blue screens with "IRQL_NOT_LESS_OR_EQUAL." What hardware is the most likely cause?

Answer: Faulty RAM, overheating CPU, or unstable RAM XMP profile. Run MemTest86 as first step.
